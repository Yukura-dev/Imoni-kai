# 動くモック

デザインツールで作った画面モック(全18画面)を、ブラウザだけで動くようにしたもの。**見た目と挙動の正解**として使う。Unity に取り込むものではない。

## 開き方
```bash
cd mock
python3 -m http.server 8000
```
ブラウザで http://localhost:8000/ を開くと一覧が出る。各画面は 390×844 で、ボタンやリンクで次の画面へ進める。

- `?speed=100` … メインゲーム(Game.dc.html)の時間を速くする(既定 10倍速)
- `?demo=true` … メインゲームを途中(2分経過・素材あり)の状態で開く
- `?fail=true` … 芋煮会演出(Imoni.dc.html)を失敗版にする

## ファイルの読み方
- `<x-dc>` の中がレイアウト(HTML+インラインCSS)。数値はそのまま USS に移せる
- `{{name}}` は下の `<script data-dc-script>` の `renderVals()` が返す値
- `<sc-for>` は繰り返し、`<sc-if>` は条件表示、`<dc-import>` は別画面の埋め込み
- `support.js` はこの記法をブラウザで動かすための小さなランタイム(モック専用)
