# M8 演出・AnimatedPot の変更

## 元絵の再利用

ユーザー指定の `Assets/ImoniUI/Home/home_pot.png` を唯一の鍋の絵とした。演出と Home はたき火付き、Waiting / Loading / Endless は下部を切り取ったたき火なし版を使う。元画像は改変せず、Setup が本体と3本の湯気を crop し、既存の UIRuntimeAssets 自動収集に登録する。切り出しが変わらない再実行では PNG 内容も変わらない。

`AnimatedPot` は既存の Campfire / Small / Large と steam / sway を維持する。湯気の元画像座標を本体と同じ倍率で配置し、従来の時間ベースの湯気アニメーションを適用する。Steam=false のときは湯気だけを非表示にする。既存の部品外枠寸法を変えず、切り出し画像を縦横比を維持して内接させる。

元絵に里芋が含まれるため、Loading 専用の楕円を重ねる旧コードは削除した。旧 pot_campfire / pot_small / pot_effect の配布ファイル自体は残すが、この部品と芋煮会演出では参照しない。

## 汁面と操作ボタン

元絵の汁面中心 (774,360) を画面 (195,536) に写す。幅264px、比率維持で高さ199.3693px、左上(63,502.0415)。拡大中心も汁面そのものの (50%,17.032967%) としたため、着地時の拡大で汁面が上にずれない。たき火の下端は約701.41px、結果ボタンの上端704pxより上に収まる。汁面の光も同じ中心へ移動した。式と全設定値は `docs/IMONI_EFFECT_SPEC.md` 9章。

## Safe Area

HUD・文字・操作ボタンのレイアウトは Safe Area の内側に維持する。その構図の座標系へ ScreenHost の全画面範囲を逆変換して、背景・虹・白フラッシュ・失敗の覆いを広げる。光柱の上端、ラインの移動範囲、放射光の大きさも拡張する。World が揺れたときの余白は Core の演出設定にある振幅から算出する。

これにより「セーフエリアを適用した演出の上にアプリの黄色い帯だけ残る」状態を解消する。アプリ外の OS ステータスバーそのものの制御は変更しない。
