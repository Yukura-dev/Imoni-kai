# M8 共通部品の表示修正

## ProgressBar の端

タイトルのバーは外側の角丸が 9px、枠が 3px で、内側の角丸は 6px になる。従来は塗りにも固定の 8px を設定していたため、100% のときに両端の内側へクリーム色のすき間が残っていた。

`ProgressBar` は描画済みの外側角丸・枠幅・塗りの幅と高さから、内側に合う角丸を計算する。画面ごとの高さの上書きや Thick / Thin / Rainbow に共通で適用し、狭い塗りの幅では半径を収まる範囲に制限する。枠内を幅 0〜100% で埋める既存の構造は維持する。幾何情報が変わったときだけ更新し、同じ半径を繰り返し代入しない。

## ImoniButton のアイコン

Icon バリエーションの固定 `left` を廃止し、ボタンの内側の中央に対して X/Y とも 50%＋自身の半分の移動で配置する。枠幅やアイコン寸法が異なるホームの設定・タイトルの設定・閉じるボタンでも中央が一致する。文字付きボタンと Action ボタンの配置は各バリエーションのまま。

## QualityChip の未公開表示

`QualityChip.Locked`（UXML は `locked`）を追加した。`true` のときは名前を `???` とし、倍率を表示しない。`ShowMultiplier` で指定したチップの寸法は維持する。色は Theme の `--c-quality-locked-bg` / `--c-quality-locked-fg` / `--c-quality-locked-border` を使用する。解除時は元の品質名・倍率・品質色に戻る。

どの品質を隠すかの判断は画面側が渡す。部品内では解放条件やゲームルールの計算を行わない。チュートリアル 3/3 は神話・超越・究極にこの属性を指定する。

## 確認観点

- タイトルの完了時（100%）で、塗りが丸い枠の内側まで埋まり、両端にすき間が残らない。
- ComponentGallery の Thick / Thin / Rainbow の 0%・50%・100% で、塗りが枠からはみ出さず、途中の端も丸い。
- Loading、ゲームの素材目標・採集、結果の素材表示でも同じ ProgressBar の変更が反映される。
- ホームとタイトルの設定アイコン、および BottomSheet の閉じるアイコンが枠の中央にある。
- チュートリアル 3/3 の通常〜伝説は従来表示、神話・超越・究極はグレーの `???` で倍率が出ない。

実画面の修正前後画像、Unity の再コンパイル結果、Core 全件テスト結果は M8 統合検証で `docs/validation/m8/` に記録する。
