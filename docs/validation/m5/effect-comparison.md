# M5 芋煮会演出の比較記録

390×844のUnity Gameビューを25fpsで録画し、配布動画と比較した。Coreの確定結果を使う通常ルートと、配布モックの18,420点／7,350点を使う明示的な検証用プレビューは分離している。以下の演出時刻は `effectReview.seed=40410` のプレビューで、実ゲームの精算値を変更していない。

## 比較する時刻の基準

配布静止画と配布動画は同じフレームを保存したものではない。例えば `41_Imoni_mid.png` はLv.3・6,923点だが、`design/videos/imoni_success.mp4` の元動画4.60秒はLv.1・1,951点だった。指定されたUnity4.60秒はLv.2・表示4,387点であり、静止画に合わせるために撮影時刻やゲーム内の時間を変更していない。

`40 / 41 / 42` は演出開始から1.50 / 4.60 / 9.00秒、`44 / 45` は4.00 / 9.00秒の指定を維持する。固定時刻の比較画像におけるスコア・レベル名・落下中の食材・星の個別配置の差を、座標の崩れと混同しない。

配布動画には演出開始前の空白がある。各フレームを32×64 RGBへ縮小して無彩色から有彩色への切り替わりを調べ、境界の画像を目視確認した。25fpsのため測定分解能は0.04秒。

| 配布動画 | 演出前の内容 | 最初の演出フレーム（0始まり） | 元動画の開始位置 |
|---|---|---:|---:|
| `imoni_success.mp4` | 0フレーム目は灰色、1〜18フレーム目は白 | 19 | 0.76秒 |
| `imoni_fail.mp4` | 0〜5フレーム目は白 | 6 | 0.24秒 |

原本の時刻をそのまま保った左右比較に加え、開始を揃えた比較では**参考側だけ**成功0.76秒／失敗0.24秒を先頭から除き、Unityは0秒から並べる。倍速、速度調整、イベントごとの時刻合わせは行わない。配布原本は変更しない。

## 時刻差の実装監査

Coreとモックはどちらも `x=(spawn-500)/(6800-500)`、累積予定点 `round(target*x*x)` を使い、出現時のレベルに応じた落下時間が終わってから加点する。Lv.3の約6,000点には `spawn≈4097ms` と直前レベルの落下780msが必要で、最短でも約4.87秒。したがって、演出経過4.60秒を静止画41のLv.3に合わせて早めることは元の式に反する。

閾値も仕様に従い、固定1000/3000/6000/10000/15000ではなく `round(levelThresholdRatios × 成功参照スコア)` を使う。失敗でも表示・精算スコアをモック値へ置き換えず、確定結果の実スコアを保持する。

検証コマンド：`dotnet test tools/CoreTests --no-restore --logger 'console;verbosity=minimal'`。全300件成功、失敗0・スキップ0。演出関連の絞り込みは `--filter 'FullyQualifiedName~ImoniEffect'` で23件成功、失敗0。

## Delaの太さの差の調査

最終画像でも「芋煮／完成!!」の字画は配布モックよりやや細い。フォント参照の取り違えを調べ、次を確認した。

- `Theme.uss` の `--font-title` は `DelaGothicOne SDF.asset` を参照し、そのSourceFontFileのGUIDは配布済み `DelaGothicOne-Regular.ttf` と一致する。FaceInfoは `Dela Gothic One / Regular`。
- 当該SDFのfallback表と各weightの代替書体表は空で、別の日本語書体への差し替え設定はない。
- TTFのcmapを直接読み、芋・煮・完・成・未のglyphをそれぞれ5932・4324・2032・2762・3295として確認した。必要文字が配布フォントにない、という原因ではない。
- 同じ配布TTFをWindowsの文字描画で58pxのRegular／Boldとして描画すると、RegularはUnityの字形と一致し、合成Boldではモックのように字画の隙間が大きく埋まる。ブラウザのh1とUnity SDFでは合成太字の厚みが異なる。

別フォントへの置換を示す参照設定は見つからなかった。Delaの指定サイズ58px（失敗52px）、Bold、縁取り3px、影4pxという仕様を維持し、差を隠すためのサイズ拡大や縁取り増加は行わない。**字画の太さの完全一致は未達**として、この描画方式の差を残す。

調査図 [`font-rendering-reference.png`](font-rendering-reference.png) は、配布TTFをWindows `System.Drawing` の `PrivateFontCollection` に読み込み、58pxで上段Regular／下段Boldを描画したもの。文字列は「芋煮 完成!!」、縁取りなし・黒字。**Unity Gameビューのキャプチャでも、モックの描画でもない**。同じフォントの合成太字による字画差を確認するための参考図として保存した。
