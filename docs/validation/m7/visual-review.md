## 固定モックとのデータ差、比較の出典

- 目標、在庫、スコア、称号、バッジ、順位は実際の Core と保存プロフィールの値。モックの固定サンプル値を再現するための上書きは行っていない。ランキングは端末内の実記録数だけを表示する仕様であり、モックのダミー多数行とは一致しない。「記録があるのに1行も見えない」初回不具合とは区別し、最終画像では実在する1行が表示される。
- 会員証の青い無地写真枠とWaiting/Loadingの無地の丸は、19_Member・15_Waiting・18_Loading_doneのモックと一致。写真用カメラアイコンはTutorialの編集可能状態だけに表示する。これらをキャラクターの描画欠けとして変更しない。
- 音ボタンの「音あり」は保存済み ON 状態を示す。モックの「タップで音ON」とは初期状態が異なる。
- `compare_Clear.png` の左は **M5 の Unity 画像 `docs/validation/m5/proof_normal_clear.png`**。Clear の専用モックではなく、結果画面と同じスタイルを継続していることの参考。
- 新規 Login、Endless 移行、Endless R6／結果には同名の専用モックがない。Simulator の単独画像で確認し、既存部品と Result／Clear のスタイルを基準にする。`compare_23_Ranking_endless.png` の左は既存のランキング用モックであり、Endless 移行画面の参考画像とは別。
